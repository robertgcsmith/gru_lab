# gru_lab  

**Purpose** This active directory contains informal, exploratory experiments on mathematical reasoning and OOD extrapolation using GRU architectures. It serves as a sandbox for informal, non-production, scratchpad scripts used for hypothesis generation and to explore back of napkin ideas. The repo is made public should anyone find interest in any of scratchpads from an open science perspective.  

**Scope**  The laboratory includes educational implementations, synthetic tasks, experimental scripts, visualisations, computational analyses and informal research notes.  It is not a production framework or a substitute for independently verified research experiments.  
 
**Structure** Each folder contains a separate GRU archiecture whose implementation servers an individual purpose to ask distinct sets of questions. There is little coherence between implementations. As explained under **Purpose**, this repo is generally a place for me to dump informal, non-productions experiments (to which I may return in the future for research purposes).
