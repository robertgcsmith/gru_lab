# Cue-Shortcut Counting Experiment
This folder contains an exploratory PyTorch experiment accompanying the research note [*Convergence is not counting*](https://rgcsmith.com/convergence-is-not-counting/). The primary experiment concerns the training of a
single layer GRU to distinguish 64 token binary sequences containing 31 vs 33 target symbols. An appended final cue token is either 95% predictive or uninformation. Paired cue flip interventions and pre-cue linear decodability probe on the final state $h_64$ track whether the network relies on the shortcut or encodes class information from the sequence across optimisation. `test_experiments.py` is a quick sanity check, while `experiment.py` is for the CLI runs, and the accompanying `lab_journal.ipynb' contains the experiment notes and results.
